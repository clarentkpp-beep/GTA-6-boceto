# GTA Intelligence v4 — mapa comunitario (prototipo)

## Incluye
- Mapa conceptual estilizado de Leonida con zoom.
- Modo «Añadir marcador»: toca el mapa, completa nombre, categoría, zona y descripción.
- Categorías: misión/consejo, ubicación, actividad, coleccionable y teoría.
- Filtro de categorías y lista de marcadores aportados.
- Los marcadores se guardan en localStorage del navegador.

## Limitaciones
- El mapa es una ilustración conceptual, no el mapa oficial ni a escala de GTA VI.
- Las aportaciones son locales a un solo navegador/dispositivo y no son visibles para otros usuarios.
- Para compartir aportaciones entre usuarios hay que añadir autenticación, base de datos y moderación (por ejemplo, Supabase).
- Es un proyecto independiente, no afiliado a Rockstar Games.
